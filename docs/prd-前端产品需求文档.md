## 1. 产品定位

一句话定位：**面向全民反诈教育的 AI 实战演练平台**——通过模拟来电对抗、互动剧场推演、智能问答诊断三种训练形态，让受训者在"被骗"的安全模拟环境中建立防御本能，并产出可量化的防骗能力画像与复盘报告。

当前状态：已有可运行 MVP（本地硬编码剧本 + ADP 实时生成双轨），本 PRD 用于指导**前端体验的 SaaS 化重构**与后续迭代。

---

## 2. 目标用户

| 角色 | 描述 | 核心诉求 | 关注页面 |
|---|---|---|---|
| **受训学员** | 学生、市民、企业员工，独立完成训练 | 快速进入训练、过程沉浸、结果易懂 | 首页、模拟来电、互动剧场、复盘报告 |
| **教官 / 管理员** | 学校安全部门、社区民警、企业安防人员 | 组织训练、追踪学员表现、定位薄弱环节 | 统计看板、历史记录、复盘报告 |
| **访客 / 演示者** | 无 AppKey 配置环境的参观演示 | 不配置任何密钥也能跑通全流程 | 首页（本地样例模式） |

设计原则：**学员路径要"浅"**（从打开页面到开始训练 ≤ 2 次点击）；**教官路径要"全"**（数据可下钻到单次演练对话）。

## 3. 核心使用场景

**场景 A：单人自主训练（学员）**
1. 学员打开首页，看到三种训练入口 + 场景快捷选择。
2. 选"模拟来电"→ 进入电话对抗，接听、对话、挂断。
3. 挂断后自动生成复盘报告：评分、五维画像、漏洞清单、专家建议。
4. 可再次挑战同一场景（分数对比），或换场景。

**场景 B：教官组织实训（管理员）**
1. 教官进入统计看板，查看整体防骗指数、演练场次、拦截率。
2. 下钻到历史记录，点开某学员某次演练的完整复盘。
3. 定位高频漏洞（如"转账指令轻信"），针对性安排训练。

**场景 C：现场演示（访客）**
1. 未配置 AppKey 时，首页明确提示"演示模式"。
2. 三种训练均可使用本地样例剧本完整跑通，标注"本地样例"来源。
3. 演示不产生真实统计数据（避免污染看板）。

**场景 D：AI 实时生成（核心差异化）**
1. 学员在互动剧场输入任意骗局关键词（如"刷单返利"），ADP 工作流实时生成剧本。
2. 多轮对话中 AI 持续生成 A/B/C 抉择，选后揭示防骗手册。
3. 生成失败或超时 → 自动降级本地剧本，流程不死。

### 4.1 全局框架（三件套）

| 组件 | 模块结构 | 说明 |
|---|---|---|
| 顶部栏 | 品牌 Logo 区 ｜ 主导航（首页 / 看板 / 历史）｜ 系统配置入口 ｜ 学员编号标识 | 桌面端固定置顶；SaaS 化后配置入口收敛为齿轮图标 + 弹窗，不再占首页大段区域 |
| 侧边栏（桌面 ≥768px） | 图标导航（首页 / 看板 / 历史）+ 底部"系统状态"指示（引擎就绪/未配置） | 窄图标栏（约 80px），hover 展开文字提示 |
| 底部栏（移动端） | 首页 / 看板 / 历史 + 居中"开始训练"主按钮 | 主按钮作为全局训练入口，提升移动端转化 |

**交互要点**
- 三处导航同一状态源（`activeView`），切换即高亮。
- 移动端：训练类模块全屏化；桌面端：弹窗居中。

### 4.2 首页仪表盘（Home）

**页面目的**：让学员 2 秒内看懂"这里能练什么"，1 次点击进入训练。

| 模块 | 结构 | 当前状态 → SaaS 化建议 |
|---|---|---|
| 欢迎区 Hero | 标语（Defend & Discern.）+ 一句话定位 + 右上指标卡 | 保留品牌感，压缩高度；标语可改为中文优先 + 英文点缀 |
| 主训练卡（模拟来电） | 大卡 + 快捷场景 chips（公检法/刷单/百万保障/退改签） | 保持为主 CTA；SaaS 化后改为"场景选择器"组件，可展开全部场景 |
| 副训练卡（互动剧场 / 反诈问答） | 两张等分卡 | 保持；hover 反馈统一为"抬升 + 描边" |
| 系统配置区 | 折叠面板：AppKey / 学员编号 / 音色选择 / 试听 | ⚠️ **当前占首页半屏，建议迁出**：改为顶部栏齿轮弹窗，首页只留"引擎状态"一行提示（未配置时） |

**空状态**：AppKey 未配置 → 首页顶部显示橙色提示条"演示模式：未配置 ADP 密钥，使用本地样例剧本"，而非报错。

**加载状态**：页面为纯静态，无需骨架屏；仅场景卡来源标记（AI 实时/本地）在配置变化时更新。

### 4.3 统计看板（Analytics）

**页面目的**：教官视角的数据总览与下钻入口。

| 模块 | 结构 |
|---|---|
| 页头 | 标题 + 说明 + 时间范围选择器（近 7 天 / 30 天 / 全部） |
| 指标卡区 | 4 张：综合防骗指数 / 实训演练场次 / 精准识破拦截率 / 模拟挽回损失 |
| 五维画像区 | 权威抵抗 / 贪婪抵抗 / 核实习惯 / 隐私意识 / 紧急冷静 5 条能力条 + 描述 |
| 档案列表区 | 演练历史记录列表（场景 / 分数 / 结果 / 时间）→ 点击打开复盘报告 |
| 底部 CTA | "开启新一轮实训"按钮 |

**交互要点**
- 档案列表支持按场景筛选、按分数排序（SaaS 化后补）。
- 指标卡点击 → 跳转对应维度明细。

**空状态**：无演练数据 → 居中插画 + "还没有演练记录，点击开启第一场实训"，并给出"开始训练"按钮。

**加载状态**：数据异步加载时，指标卡区域显示轻量骨架卡（4 张占位）；列表区显示 3 行占位行。

**错误状态**：数据拉取失败 → 卡片区显示重试按钮，不白屏。

> ⚠️ **数据缺口**：当前 `AnalyticsView` 使用本地写死的 `INITIAL_ANALYTICS_DATA`，无真实统计链路。PRD 要求：统计必须来自真实演练记录（演练结束时写库/上报），演示模式数据不混入。

### 4.4 历史记录（History）—— ⚠️ 待实现页面

**页面目的**：学员/教官查看个人全部演练档案，支持检索与对比。

| 模块 | 结构 |
|---|---|
| 页头 | 标题 + 筛选（场景 / 结果 / 时间范围）+ 搜索框 |
| 记录列表 | 每条：场景名、日期时长、分数、风险等级、查看入口 |
| 分页/加载更多 | 默认每页 20 条 |

**空状态**：无记录 → "你还没有演练记录" + 开始训练 CTA。
**加载状态**：首屏骨架列表；筛选时列表区 spinner。
**错误状态**：接口失败 → 错误提示 + 重试。

> 当前 `ActiveView` 类型已含 `'history'` 但路由未实现——本页是本次重构的**最小增量**之一。

### 4.5 功能模块 · 模拟来电（SimulatedCall）

**目的**：语音/文字双通道的实时骗局对抗。

| 模块 | 结构 |
|---|---|
| 顶部状态栏 | 来电人姓名 / 号码 / 场景标签 / 通话计时 / 挂断按钮 |
| 对话区 | 来电人消息（左）+ 学员回复（右），流式渲染；关键话术命中标注危险关键词 |
| 输入区 | 语音按钮（按住说话）+ 文字输入框 + 发送 |
| 风险指示器 | 实时压力值 / 话术战术标签（可选展示） |
| 结束浮层 | 挂断 → 生成报告过渡动画 |

**加载状态**
- 首次对话（语音/文字）发出后：气泡旁"思考中"三点动画；语音模式额外显示"正在转写…"。
- 来电开场语音播放中：显示"接听中"脉冲动画。

**空状态**：无（有本地场景兜底，场景列表为空时显示"暂无可用场景" + 回首页）。

**错误状态**
- 麦克风权限被拒 → 提示"无法使用语音，可切换文字模式"（自动降级，不阻塞）。
- ADP 生成超时 → 提示 + 自动切本地剧本继续对话。

### 4.6 功能模块 · 互动剧场（InteractiveTheater）

**目的**：多轮聊天式 DM（主持人），AI 实时生成剧情与抉择，选后揭示防骗手册。

| 模块 | 结构 |
|---|---|
| 顶部栏 | 返回 / 场景标签 / 引擎来源标识（AI 实时生成 / 本地样例） |
| 消息区 | DM 消息流式渲染；A/B/C 选项按钮组；选后该轮标记已选 + 揭示隐藏手册卡片 |
| 指令区 | 底部指令芯片：再来一轮 / 换个场景 / 复盘结束 |
| 场景切换 | 顶部骗局类型 chips（刷单返利 / 杀猪盘 / 冒充客服 …） |

**交互要点**
- 点击选项后：该选项高亮、其余置灰、手册卡片展开（含"你选了什么 / 正确做法 / 话术拆解"）。
- 流式输出期间不可点选项（等本轮结束）。
- AI 输出异常（主控 agent 走错分支）→ 红框诊断提示 + 自动回退本地剧本，流程不断。

**加载状态**
- 开场生成中：全屏"AI 正在编写剧本…"骨架（场景名 + 进度文案）。
- 每轮反馈生成：消息区底部三点动画。

**空状态**：场景列表空 → "暂无场景，请输入自定义骗局关键词" + 输入框。

**错误状态**
- 生成失败：错误条（可展开原始报错）+ "使用本地剧本继续"按钮。
- 超时（>90s）：提示 + 本地剧本兜底。

### 4.7 功能模块 · 反诈问答（AntiFraudQA）

**目的**：基于反诈知识库的问答诊断（粘贴可疑短信/指令，实时拆解）。

| 模块 | 结构 |
|---|---|
| 对话区 | 用户粘贴内容 + AI 诊断回复（话术特征 / 风险等级 / 处置建议） |
| 输入区 | 大文本框 + 快捷示例按钮（"贴一段可疑短信"） |
| 诊断结果卡 | AI 回复内的结构化结论高亮（风险等级徽章 / 关键词命中） |

**加载状态**：发送后"正在调取话术特征库…"。
**空状态**：首屏引导文案 + 1~2 个可点击示例。
**错误状态**：ADP 不可用 → 提示 + 提供静态话术库兜底回答（或明确"离线模式"）。

### 4.8 功能模块 · 复盘报告（ForensicReport）

**目的**：一次演练的完整复盘档案，可读、可分享、可下钻。

| 模块 | 结构 |
|---|---|
| 报告头 | 案件编号 / 场景 / 时间 / 时长 / 总分 |
| 风险等级 | 大徽章：极低 / 中低 / 中等 / 高危易受骗 |
| 五维雷达 | 雷达图（5 轴能力分） |
| 漏洞清单 | 检测到的弱点列表（带原文引用） |
| 话术拆解 | 演练中暴露的骗术点 + 正确应对 |
| 专家建议 | 3~5 条可执行建议 |
| 对话记录 | 完整对话回放（折叠展开，按压力值着色） |

**交互要点**
- 顶部操作：导出 / 复制报告（文本摘要）。
- 对话回放默认折叠，展开后按时间轴滚动。

**空状态**：报告数据缺失 → "报告生成失败" + 重试 / 返回。
**加载状态**：报告生成中 → 骨架 + "正在生成复盘报告…"（来自真实演练时长）。

### 4.9 系统配置（重构为全局弹窗）

**目的**：把散落在首页的配置收敛为顶部栏齿轮入口。

| 模块 | 结构 |
|---|---|
| 密钥区 | ADP AppKey（明文输入 + 保存） |
| 学员区 | 学员编号 + 生成随机编号 |
| 音色区 | 6 个 Edge 音色单选 + 试听按钮 |
| 状态区 | 引擎连接状态（就绪 / 未配置 / 错误） |

**保存即生效**：所有配置 localStorage 持久化，无需显式"保存"按钮（当前有冗余的保存按钮）。

## 5. 视觉风格关键词（SaaS 化）

当前项目为 **Neo-Brutalism（新粗野主义）**：米白底 `#FAF9F6`、墨黑 `#141414`、品牌橙 `#FF4D00`、粗边框、硬阴影（`4px 4px 0`）、衬线斜体大标题、等宽字体标签。

SaaS 化改造方向——**"克制的编辑部风"（Refined Editorial SaaS）**，保留品牌记忆点，去掉装饰性压迫：

| 维度 | 当前 | 目标 |
|---|---|---|
| 主色 | 黑白高对比 + 橙 | 保留品牌橙 `#FF4D00` 作唯一强调色，降低黑块占比 |
| 背景 | 米白 `#FAF9F6` | 保持，微调为中性灰白 `#F7F7F5` |
| 卡片 | 粗边框 + 硬阴影 | 细边框 `1px #E5E2DC` + 轻投影，hover 时 2px 品牌橙描边 |
| 圆角 | 直角（brutalism） | 6~8px 小圆角（SaaS 通用语言） |
| 标题 | 衬线斜体超大标题 | 标题用无衬线加粗，衬线斜体仅保留 Hero 标语 |
| 标签 | 等宽大写英文标签 | 保留等宽标签作为"编辑腔调"，但减少出现频率 |
| 反馈 | 纯色块 hover 翻转 | 统一为描边 + 填充过渡、状态徽章体系 |
| 密度 | 大留白、大字号 | 信息密度提升 20%，指标区可一屏看完 |

**关键词清单**：`克制`、`卡片化`、`清晰层级`、`品牌橙点缀`、`中性底色`、`专业可信`、`编辑器腔调（mono 标签）`、`流畅动效（150-200ms ease-out）`。

**字体系统**：中文主字体（系统无衬线，如 PingFang/思源黑体）、英文标题字体（保留现有衬线斜体仅 Hero）、等宽字体（标签/编号/代码类信息）。

## 6. 全局交互规范

1. **导航**：三处导航共享同一状态源；页面切换淡入 150ms。
2. **弹窗**：桌面端居中弹窗（最大宽 480px，训练类全屏 720px+），遮罩半透明黑 + 点击遮罩不关闭训练类（防误触丢进度），Esc 可关。
3. **表单**：输入框 focus 描边品牌橙；错误即时内联提示；保存即时生效（localStorage）。
4. **反馈体系**：统一三种反馈——Toast（操作成功，2.2s 自动消失）、Inline Error（表单/流程内错误）、Banner（全局性警告如"未配置 AppKey"）。
5. **危险操作**：挂断/结束训练二次确认浮层（保留"继续训练"主出口）。
6. **键盘可达**：所有训练入口可 Tab 聚焦 + Enter 触发；选项按钮支持 1/2/3 快捷键（可选）。
7. **无障碍**：正文对比度 ≥ 4.5:1；图标操作带 aria-label。

## 7. 加载 / 空 / 错误状态矩阵

| 页面/模块 | 加载态 | 空状态 | 错误态 |
|---|---|---|---|
| 首页 | 无需 | AppKey 未配置 → 演示模式提示条 | — |
| 统计看板 | 4 卡骨架 + 列表占位 | 无数据 → 引导开始训练 | 拉取失败 → 重试按钮 |
| 历史记录 | 列表骨架 | 无记录 → 引导 CTA | 失败 → 重试 |
| 模拟来电 | 三点思考动画 / 转写中 | 场景空 → 回首页引导 | 麦克风拒绝 → 降级文字；超时 → 本地剧本 |
| 互动剧场 | 开场"AI 编写剧本中"全屏骨架 / 每轮三点动画 | 场景空 → 自定义关键词输入 | 生成失败 → 错误条 + 本地剧本按钮；路由异常 → 红框诊断 + 回退 |
| 反诈问答 | "调取话术库中…" | 首屏引导 + 示例 | 离线 → 静态话术兜底 |
| 复盘报告 | 报告骨架 + 生成动画 | 数据缺失 → 重试/返回 | 失败 → 重试 |

**总原则**：任何 AI 相关能力失败，**永不白屏、永不卡死**——一律降级到本地可跑通的替代路径，并明确告知用户当前处于什么模式。
